# REGLAS DEL PROYECTO - Smart Calculator

## Reglas que Claude debe seguir en este proyecto:

### 1. Idioma
- **SIEMPRE hablar en ESPAÑOL** en todas las comunicaciones
- Tanto preguntas como respuestas deben ser en español

### 2. Control de Versiones (Git)
- **PROHIBIDO usar comandos de git**
- El desarrollador se encargará de todos los commits, push, pull, etc.
- No sugerir ni ejecutar comandos git

### 3. Confirmación antes de Cambios
- **NO realizar cambios o ajustes sin preguntar antes**
- Siempre pedir confirmación antes de modificar código
- Explicar qué se va a hacer antes de hacerlo

### 4. Análisis de Errores
- **Analizar detalladamente** cuando se presente algún error
- Investigar la causa raíz antes de proponer soluciones
- No hacer suposiciones apresuradas

### 5. Verificación de Funcionamiento
- **Verificar que todo funciona bien** al finalizar cualquier ajuste
- No entregar cambios con errores
- Probar la funcionalidad después de cada modificación
- Ejecutar builds o tests según sea necesario

### 6. Continuidad del Proyecto
- Leer este archivo al inicio de cada sesión
- Actualizar el archivo CONTEXTO_PROYECTO.md con el progreso
- Mantener registro detallado de cambios realizados
